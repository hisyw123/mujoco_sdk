[2026-10-03 / 원본 유지형 MuJoCo 이식 1차]

1. reference/raisim/{src,scripts,README.md,CMakeLists.txt}
   기능: 다운로드 폴더의 RaiSim 원본 코드 보존. 원본 C++/Python을 읽기 비교 기준으로 사용.
   실행 대상 아님. 원본과의 일치 여부는 audit manifest에서 확인.

2. scripts/mujoco_sim.py (신규)
   기능: 원본 augmented_sim의 replay/rollout CSV 프로토콜을 MuJoCo Python API로 구현.
   유지: 구간 시작 실측 q/v 초기화, 시작 질량행렬, M*(v_real_end-v_nom_end)/T 라벨,
         stride/offset, 구간 내 ff 유지, 기본 로그별 dt 및 목표 갱신,
         steps 지정 시 등분 dt와 시작 목표 유지, fixed-dt 참조 선형보간/목표 ZOH,
         전체 관절 TorchScript GRU 추론, recurrent state 유지, 기존 CSV 출력 블록.
   변경: RaiSim 내장 implicit PD -> 외부 sampled PD torque + mj_step(Euler).
         엔진 결과가 수치적으로 같다고 주장하지 않음. 라벨 재생성/재학습 필요.
         replay마다 mj_resetData하여 warmstart/이전 force/time 등 내부 상태도 초기화.
         접촉/native actuator 비활성화. 관절 limit/passive 특성 유지.
         free/ball/equality/tendon/mimic 명시 거부. 무단 관절 제거 없음.
         비정상 dt/상태/엔진 warning 거부. 출력 CSV overwrite 거부.
         joint-config로 CSV 순서와 qpos/dof 인덱스 매핑 및 관절별 PD 게인 지원.

3. scripts/common.py (원본 복사 후 수정)
   기능: 기존 전처리와 시뮬레이터 호출 연결.
   유지: Hann smoothing, 중복 시간 첫 행 유지, feature 순서, block_mask, prediction_rate.
   변경: C++ 실행파일 대신 현재 Python의 mujoco_sim.py 호출.
         joint_names를 URDF 문서 순서 추정 대신 컴파일 모델/명시 joint-config에서 읽음.
         kp=0/kd=0을 False와 혼동해 누락하던 옵션 전달 조건 수정.
         컴파일 모델 SHA256/엔진/PD/관절 순서를 기록하는 simulator_contract 추가.
         합성 수집 meta가 있으면 CSV 해시/게인/순서 검증. 실기 meta 없는 로그는 경고 후 허용.

4. scripts/train.py (원본 복사 후 최소 수정)
   유지: 전체 관절 GRU, feature 선택, 학습 데이터 기준 정규화, BPTT 창과 warmup,
         매 4번째 시간 블록 validation, 겹치는 창 및 마스크 방식,
         Adam/cosine/gradient clipping/early stop/최선 가중치/TorchScript 출력.
   변경: 백엔드 설명, simulator 계약 저장, 입력 meta 확인,
         빈 검증 구간/짧은 로그/비어 있지 않은 출력 폴더 등 오류 선제 검사.
   원본 블록 분할의 상관/문맥 공유 한계도 유지했다. 독립 파일 검증으로 몰래 바꾸지 않았다.

5. scripts/evaluate.py (원본 복사 후 최소 수정)

7. scripts/collect.py (신규, 원본 수집기의 포팅이라고 주장하지 않음)
   원본 저장소에는 실제 로봇 수집 구현이 없다. CSV 소비 코드/수집 요구사항만 있다.
   기능: 고정 dt, 정현파+smoothstep 램프, seed별 위상, 원본 CSV 필드,
         true q/v 및 command 추가 로깅, 시뮬레이션 출처/설정/해시 meta 기록.
         관측 q/v 노이즈와 물리 불일치(torque scale/extra damping)를 분리.
   PD feedback은 true state이며 sensor noise는 상태를 덮어쓰지 않는다.
   목표 생성기/노이즈 모델은 새 검증 도구이며 실제 로봇 수집 방법과 동일하지 않다.
   실제 하드웨어 통신, 외부 목표 CSV, 관절별 궤적/노이즈, saturation/lag는 미구현.

   검증: 테스트 11개 통과.
   동일 모델 zero residual 및 free rollout 일치, 관측노이즈 truth 보존,

9. runs/smoke, runs/verified (자동 생성 시험 산출물)
   3초/1 kHz 합성 로그, stride=2, smooth=1, kp=10, kd=.5,
   torque_scale=.9, extra_damping=.1, GRU hidden16/1layer, 3epochs/batch16.
   수집 -> replay -> 학습 -> TorchScript -> 전체 평가/그림 성공.
   verified 위치 RMSE: baseline 약 9.455465e-4 rad, augmented 약 9.355287e-4 rad.
   위치 약 1.1% 개선, 속도 약 2.4% 악화. 성능 개선 입증 아님.
