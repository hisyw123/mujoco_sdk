빌드: 독립 CMake Release 빌드 성공.
계약: 28/28 actuator binding, ONNX obs[1,45] -> actions[1,12] 검증 성공.

           Off/Estop 전체 출력 차단, 비정상 값 차단, checkpoint 불일치 거부 성공.
Python ORT vs C++ ORT: 65개 입력, 출력 최대 절대 차이 0.
GUI: Xvfb에서 메인 창+진단+depth 동시 실행 및 정상 종료 성공.
